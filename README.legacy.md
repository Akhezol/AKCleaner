# AKCleaner

AKCleaner is a simple Windows application that **cleans temporary and recent files with just one click**.  
It helps you free up space quickly and keep your system tidy.

---

## 🚀 Features
- One-click cleaning  
- Deletes temp and recent files safely  
- Lightweight and easy to use  

---

## 📥 Installation
1. Go to the [Releases](#) section.  
2. Download the latest `AKCleaner.exe` file.  
3. Run it on your Windows computer.  

---

## 🖱️ Usage
1. Open **AKCleaner.exe**  
2. Click the **Clean** button  
3. Done ✅ – unnecessary files are removed
